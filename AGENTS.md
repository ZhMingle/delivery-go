# Project workflow

- After completing each task that changes this project, run the checks appropriate to the change, commit the task's changes with a descriptive message, and push the current branch to its configured upstream automatically. The user has authorized this workflow; do not ask for confirmation again unless a tool requires approval.
- Keep unrelated local changes out of the task commit unless the user asks to include them.
- Never force-push or overwrite remote history. If checks, commits, or pushes fail, report the failure accurately and preserve the work.
- Report the commit and push result when finishing the task.
